# AI-02 · Explore the new ChatGPT connection with one live PDF-page request

## Why

First prove the central opportunity: use a person's ChatGPT plan for PDF vision inference without maintainer-funded tokens.

## Scope and acceptance

- [ ] Use supported new sign-in flow and validate identity/plan-usage scope; never extract an existing app's credentials.
- [ ] List account-supported models and complete one streamed page-image request with synthetic facts; retain non-sensitive reproducible results.
- [ ] Establish hosted-PDkef compatibility; if only local flow is supported, prove locally and record the hosting limitation explicitly.
- [ ] Document minimum supported auth/token lifecycle, eligibility/credit errors and cancellation; no paid API/proxy fallback.
- [x] Deliver runnable exploration instructions and distinguish docs findings from actual live proof.
