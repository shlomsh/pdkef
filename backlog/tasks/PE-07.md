# PE-07 · Highlight: the suggestion line sends the file to Scan

*Opened 2026-11-04* from [the handoff](../../docs/scan-enhance-handoff.md), part of the page-enhancement plan.

**Route, decided by Shlomi 2026-11-04:** a crooked PDF is straightened in Scan and comes back to Highlight, not rebuilt inside Highlight. Squaring a page is not an affine move, so the vector rebuild this plan first had could not do it.

## Outcome

In the file line's status slot, a line such as "This scan is sideways, two pages to a sheet" offers Straighten and Not now. Straighten opens the same file in Scan.

## Acceptance

- [ ] Shlomi has seen the line's wording before it is built; what he picks ships as picked.
- [ ] Not now is remembered for that file.
- [ ] The line shows only when the silent check says crooked and there are no marks yet.
- [ ] The original stays in recents, so nothing is lost by going through Scan.
- [ ] Copy follows the voice guide, no em dashes.
