# PE-13 · UVDoc strategy, downloaded on request (retired)

*Opened 2026-11-04* from [the handoff](../../docs/scan-enhance-handoff.md), part of the page-enhancement plan.
*Retired 2026-11-04* by Shlomi after [SCAN-19](SCAN-19.md) measured it: dropped, no message to the authors. Reopen only if a real curled-page photo set shows level 1 failing and a permissive weights licence exists.

## Why it was dropped

- On the 8-page book, UVDoc reaches a median 4.40 px against the lean rotation's 2.03 px (noise floor about
  2 px), worsens 15 of 16 halves compared with the lean rotation, and wobbles pages that were already level.
- On Shlomi's creased letters it does not measurably repair the crease (the fold is faint shading, not a bend),
  and on flat pages it zooms and crops (ink box up to 14% wider).
- The weights licence is not established (MIT covers the repo's "Software"; the checkpoint and its training
  data are unaddressed). The rule is permissive licences for code AND weights.
- Cost: about 7.7 MB (int8 5.4 MB + runtime 2.3 MB, brotli), 0.9 s a page, about 300 MB of memory, and int8 is measurably worse
  than fp32 (the 30 MB version is what would have to ship for full quality).

## Outcome (as planned)

Would have been: an advanced learned strategy behind "Try advanced (~N MB)", loaded lazily in a
worker started from a same-origin URL, desktop only.

## Acceptance

- [ ] The authors confirm in writing that the weights carry a permissive licence (the draft message is in SCAN-19).
- [ ] A set of curled or crumpled page photos exists on which level 1 fails, and UVDoc beats it there on the
  SCAN-36 metric without cropping, zooming or hurting flat pages (use the grid's residual after its affine fit).
- [ ] Downloaded on request only, same-origin from a new models folder under public; desktop gate is fine
  pointer, deviceMemory >= 8 where reported, Save-Data off.
- [ ] The service worker's activate cleanup skips the model cache: check. (onnxruntime in a same-origin worker
  with no `wasm-unsafe-eval` on the page is verified, SCAN-19; a worker URL must carry no CSP header.)
- [ ] No file bytes leave the device.
