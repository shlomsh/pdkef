# PE-05 · assess and planPage

*Opened 2026-11-04* from [the handoff](../../docs/scan-enhance-handoff.md), part of the page-enhancement plan.

## Outcome

`assess(gray)` returns an `Assessment` of turn, turnConfidence, spine, leans (one per page, since a spread's halves lean apart), bentPx and crooked; `planPage` builds a `PagePlan { pieces }` from it. Both types start here (PE-02 made `Piece`). The split is the plan's first step and a book half is lean only: flat, inset 0, no edge curves (PE-03's numbers).

## Acceptance

- [x] One-bit pages area-averaged at 1000 px lose no rows: the book thresholded to one bit reads the same turn, spine and leans on all 8 sheets, and scores the same (median 2.01 px, worst 2.38).
- [ ] 90 versus 270 degrees: the default and the Rotate fallback follow Shlomi's answer to the open question in [the handoff](../../docs/scan-enhance-handoff.md).
- [x] The page's quarter turn is known before the bend is measured; output is sized with `warpSizeFor(pageAspect)`.
- [ ] Shlomi's photos come out upright and at 1.41 within 3%.
