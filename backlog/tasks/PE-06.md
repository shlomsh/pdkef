# PE-06 · Highlight: detect a crooked scan, no UI

*Opened 2026-11-04* from [the handoff](../../docs/scan-enhance-handoff.md), part of the page-enhancement plan.

## Outcome

Highlight renders pages for analysis in a worker (`enhance.worker.ts`) and reports whether the file is crooked, silently.

## Acceptance

- [ ] No marks needed and no visible change to the screen.
- [ ] A crooked fixture is flagged; an upright scan and a born-digital PDF are not.
- [ ] The check never blocks opening the file.
